# Security policy

Swapling reads local credentials (the Claude Code keychain item, the Codex login, browser cookies when you ask it to import them, and API keys you enter). If you find a way these could leak or be misused, please **do not open a public issue**.

Report it privately through GitHub's [private vulnerability reporting](https://github.com/AmakitaCastle/swapling/security/advisories/new) instead. Please include the affected version and steps to reproduce. You can expect a first reply within a week.

Only the latest release is supported with security fixes.
