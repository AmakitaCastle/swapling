# GPT 龙娘（Codex 平台）

原角色设计：ZipZipPipe。属于非官方二创，表情、动作和原图未展示的结构为本次补全。

- 作者主页：https://space.bilibili.com/4168597
- 作者《AI娘化》图集：https://www.pixiv.net/artworks/148186519 （第 4 张）
- 授权与署名见 [NOTICE.md](../NOTICE.md)

此目录三张 PNG：头部连同龙角约占画面高度六成，实际 96×96（面板 96pt 下每格正好 2 个屏幕像素）、按区域平均取色并清除孤立杂点、共用 31 色色板、二值透明背景。正常/紧张/休息分别使用 30/31/25 色。`pixel-art` 标记启用最近邻显示。

应用中的平台 ID 为 `codex`，账号如 `codex:work` 也继承此角色；本机自定义头像仍优先。

| 文件 | 额度状态 | 表情 |
| --- | --- | --- |
| `normal.png` | 未达到第一条提醒线（默认已用 80%） | 正常微笑 |
| `worried.png` | 达到第一条提醒线且尚未用尽 | 紧张冒汗 |
| `exhausted.png` | 额度用尽或部分模型受限 | 闭眼托腮休息 |

状态依照应用的可信额度数据和用户自定义提醒线；额度恢复后重新计算表情。
