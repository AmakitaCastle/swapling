# DeepSeek 鲸鱼娘三态

当前使用用户指定参考图制作的 v2 三态，非官方 DeepSeek 形象。

- 身份参考图由项目作者提供，原图作者及发布来源尚未核实，见 [NOTICE.md](../NOTICE.md)。
- 本次使用内置 image_gen 制作像素胸像、新表情和动作。

此目录为应用使用的 96×96 RGBA PNG，三态各 31 色，共用色板，人物完全不透明、背景透明。深紫灰描边，保留深蓝长发及浅蓝发梢、白色褶边女仆发箍、右侧蓝色蝴蝶结、鲸鳍、蓝眼及蓝白服饰。`pixel-art` 标记启用最近邻显示。

| 文件 | 形象 | 应用状态 |
| --- | --- | --- |
| `normal.png` | 睁眼微笑 | 余额为正或正常额度 |
| `worried.png` | 紧张冒汗、双手收拢 | 达到额度提醒线 |
| `exhausted.png` | 闭眼托腮休息 | 可信余额 ≤ 0 或额度用尽 |

平台 ID 为 `deepseek`，账号继承基础平台资源；本机自定义头像仍优先。当前 DeepSeek 按余额读取，正余额不套用统一的“余额不足”阈值，故紧张图作为完整三态资源保留，不新增自动触发条件。实际显示仍遵循面板的角色选择与平台交接规则。
